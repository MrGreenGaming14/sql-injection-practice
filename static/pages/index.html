Horizon Community Savings

Two ways to run this fictional, intentionally vulnerable SQL lab. GitHub Pages hosts a browser simulation; the local Flask version runs on your own machine. Neither publishes the instructor answer key.

Open the browser challenge

The GitHub Pages browser simulation is a static page at challenge.html. It runs entirely in your browser: the SQLite engine (sql.js) is fetched from a pinned public CDN and holds an in-memory database, so no Python, Flask, server, or database file is involved. Four sequential levels mirror the local lab, level progress is kept only in this browser's local storage, and a Reset lab control clears it. The SOC panel fabricates clearly-labeled events with the placeholder IP 192.0.2.42 (TEST-NET-1); GitHub Pages cannot know your real IP address or keep server logs. An internet connection is needed the first time the engine loads.

Local workshop lab (Flask)

This same fictional exercise also runs as a local Flask program. Follow the README in the repository to start it at 127.0.0.1. The local version writes real server logs during the secret-file/SOC lesson, stores its SQLite file on disk, and never sends or receives network traffic beyond your machine. The two modes are separate; progress is not shared.

Safety

Never expose the lab remotely or use its techniques on systems without explicit permission. All accounts and files are fake. The final transfer lesson never moves money in either mode: the browser version only reads from an in-memory database, and the Flask version rolls back by design.
